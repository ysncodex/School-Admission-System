# AI usage disclosure

AI assistance was used during the development of this take-home project.

## Tool used

- ChatGPT (OpenAI): requirements decomposition, architecture planning, initial code scaffolding, API implementation drafts, frontend component and styling drafts, Docker configuration, documentation drafts, and test-case design.

## Areas where AI assistance was used

- Translating the supplied assignment into implementation tasks and explicit assumptions.
- Drafting the .NET 10 / EF Core / PostgreSQL API structure and reservation workflow.
- Drafting PostgreSQL row-locking and uniqueness-constraint implementation for concurrent seat allocation.
- Drafting React + TypeScript UI components, validation helpers, and polling/countdown behaviour.
- Drafting Dockerfiles, Docker Compose, README, ASSUMPTIONS.md, and automated test scaffolding.

## Human review and verification

AI-generated code must be reviewed, understood, and tested before submission. The developer is responsible for checking the implementation, resolving compiler or runtime issues found in the local environment, verifying the requirements against the assignment, and being able to explain the design decisions and tests during an interview.

No claim is made that AI-generated code is correct solely because it was generated. The final submitted repository should reflect the developer's own review and understanding of every included part.
